Programa em COBOL que lê um arquivo de contas (vide BOOK BOOKCLI.CPY) e gera um arquivo de saída com estatísticas de contas válidas.

É possível executar o script gerar_registros.py para criar um arquivo de entrada de tamanhos variados.

## Aplicativo de delivery

O projeto também contém o Bora! Delivery, uma aplicação demonstrativa em React e Java/Spring Boot com autenticação, catálogo fictício de demonstração, gestão de perfil, pedidos, promoções, chat, avaliações, painel operacional e acompanhamento simulado em mapa. Pagamentos, financeiro e documentos fiscais ainda não estão integrados para operação real. Veja [DELIVERY_APP.md](./DELIVERY_APP.md) para estrutura, API, contas de teste, limites e instruções de execução.
